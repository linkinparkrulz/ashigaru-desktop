====================================================================
 ASHIGARU DESKTOP - UI REVAMP TESTING CHECKLIST
 Branch: claude/funny-cannon-itky0u
====================================================================

HOW TO USE
  - Get the branch and run it (JDK 21):
        git fetch origin claude/funny-cannon-itky0u
        git checkout claude/funny-cannon-itky0u
        ./gradlew run
  - Sections 1-6 need no funds. A throwaway wallet is enough.
  - Sections 7-10 need a funded wallet and a live coordinator. Use
    testnet with a throwaway data directory where you can:
        ./gradlew run --args="--network testnet --dir /tmp/ashigaru-test"
  - Mark each item [x] pass / [!] fail (add a note and a screenshot).
  - Items marked (UNSEEN) were built without ever being run against
    real data. Look hardest at those.
  - Every section ends with "anything odd?". Clipped text, a control
    that does nothing, a wrong colour: write it down even if it is not
    on the list.

WHAT THE REVAMP IS FOR
  Each screen should answer one of four questions better than before:
    Privacy   How private is my bitcoin?
    Path      Where does it go next?
    Exposure  Who can see what I do?
    Proof     Can I check it myself?
  If a screen leaves you unable to answer its question, that is a
  finding, even when nothing is broken.

  [ ] With swaps OFF: no Swaps tab in Tools, no "Swap to XMR" on

  [ ] With swaps ON: all three appear. Tools shows Swaps as a tab
      (there is no collapse-to-icons button any more).
  [ ] Badbank's amber bar now ends "Tick one coin and choose Swap to
      XMR...".
  [ ] "Swap to XMR" is disabled until exactly one coin is ticked, and

  [ ] "Who learns what" gains three rows: Swap makers, Monero nodes,

  Looks (the swap screens were tested on xmr-swap with a different

  [ ] Sentences and figures on the swap screens are in Roboto and

  [ ] Nothing on the offers, review or progress screens is clipped,
      wrapped badly or overlapping at the minimum window size.
  [ ] The pinned Approve bar still stays in view while the review

  Behaviour (should be exactly as on xmr-swap):
  [ ] Offers load, sort and refresh.
  [ ] Review offer shows the terms, deposit and recovery details.
  [ ] A swap runs to completion and the XMR arrives.
  [ ] A stalled or cancelled swap recovers the BTC.
  [ ] Changing the Bitcoin server, restarting Tor and requesting a new

  [ ] Tools, Logs still shows the swap engine log.
  [ ] Anything odd?


--------------------------------------------------------------------
 KNOWN GAPS  (not bugs, do not report)
--------------------------------------------------------------------
  - The selection summary shows count and total only. It does not yet
    say which pool the selection fits.
  - On Linux without a compositor, menus may show a pale halo.
  - Statistics decides "your pool" from Postmix coin value (0.025 or
    0.25 BTC).
  - The minimum window width is 1200, inherited from xmr-swap.
  - The interface is Nikkyou Sans on labels, buttons and tabs, with
    Roboto for sentences. xmr-swap alone used Roboto everywhere.
